# 可重复扩展构建与稳定重载目录

在选定的固定工程目录运行：

    npm run build:extension

输出始终为该工程的 dist/extension。脚本依据自身所在工程定位，不依赖调用时的其它工作目录；不安装依赖、不访问网络、不操作浏览器。Node 24+ 即可运行。

## 构建保证

- 只复制脚本中显式列出的 18 个源码/文档/许可证文件，另生成 BUILD-MANIFEST.json；不打包整个目录。
- 保留标准 MIT LICENSE。构建清单包含版本、每文件 SHA-256 和确定性 buildId，不包含时间、绝对路径、账号或环境变量。
- 相同源码产生逐字一致的 19 文件输出。不同构建的目录时间和备份目录名可以不同，不属于内容哈希。
- 第一次仅向不存在的输出目录构建。已有输出必须有本构建器的有效归属清单且每个文件与清单匹配；无标记、修改过的文件/清单、陌生文件或符号链接均停止，**不会自动接管或覆盖**。
- 使用独占构建锁；遇到残留锁先人工确认旧构建进程已终止，不自动删锁或抢锁。
- 更新时先校验，再把前次受管输出移到 dist/.extension-backups 中保留，然后发布新输出。备份不自动删除；确认不含需保留的修改后才由用户清理。
- 不要直接编辑 dist/extension；请修改 extension/ 或相关 docs 源文件后重建。构建期间不要由其他程序同时修改输出、锁或备份。该文件保护机制不是抵御同用户恶意并发进程的隔离边界。
- dist/（包括构建锁、暂存和备份）已加入 .gitignore，不应进入源码发布包。

## 加载或重载

由用户在已批准的本地 Google Chrome Profile 内按正常安装流程选择 dist/extension，而不是临时解压目录。已安装同一路径的扩展，可在完成重建后通过浏览器提供的正常“重新加载”操作更新。重载会重启 service worker，原发送许可不从磁盘恢复；unknown 仍不重发。

本构建脚本不会打开扩展管理页面、点击安装/重载、申请任何新权限，或绕过浏览器/管理员对受限 URL 的拒绝。源代码与固定输出存在**不证明扩展已安装或已重载**。

执行环境能读写固定目录，不意味着浏览器控制面的文件选择器也能看到它；可能属于不同文件系统或命名空间。文件选择器可见性需另行通过获准方式验证，不能据此改用调试端口、公开文件服务或其他绕过路径。

## 持久性边界

仅确认该固定路径在当前执行环境中存在且可重复构建。不承诺虚拟机重启、替换、回收或未来会话后仍保留；没有备份/持久卷的独立证据时，应保留源码归档作为恢复材料。没有任何构建或重载步骤会解除真实发送的原生身份门禁。
